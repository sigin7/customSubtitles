Movie and series search now updates automatically as you type a title or IMDb ID. Results appear after at least two characters and a 300 ms pause; Enter and the search button still search immediately.

- Cancel pending searches when the query changes and ignore responses for older queries.
- Clear results when the search text is shortened or removed.
- Search again when switching between Movie and Series.

Download **CustomSubtitles-1.1.1-Setup-x64.exe** to install or upgrade. Existing subtitles, administrator password, addon key, and connection settings are preserved. Close Custom Subtitles before running the installer, then open it again.

The installer includes Node.js 24 LTS and the optional official Tailscale installer. Only the server needs Tailscale; playback devices use the public HTTPS addon address. The installer is for Windows 10/11 x64 and is currently unsigned. SHA-256 checksums are included in `SHA256SUMS.txt`.
